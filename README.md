## 🐌 SnailGame

SnailGame is a university project developed for the "Computer–Computer Interaction" course. The project was created over one semester under the supervision of our instructor.
The goal of this project was to recreate the classic Snail game from Windows 7, bringing a nostalgic experience into a modern, interactive environment.

👥 Team
  @olsujabu
  @bzraa

💡 Inspiration
We were inspired by the childhood game Snail that was available on Windows 7. Our aim was to rebuild this simple but engaging game while enhancing user interaction using modern technologies.

🛠️ Technologies Used
TypeScript – for game logic and structure
MediaPipe – for interactive input (gesture-based control)

🎮 MediaPipe Usage : 
MediaPipe was used to enable gesture-based interaction, allowing players to control the game without traditional input devices like a keyboard or mouse. This improves accessibility and creates a more immersive user experience.
